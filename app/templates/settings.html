Agente de descarga

Es una aplicación que corre en tu computadora y baja los temas a la carpeta que elijas. Tus cuentas de SoundCloud, YouTube, Muzpa y Deezer se vinculan desde ahí. Tiene que estar abierto para que las descargas funcionen.

1Descargá el agente

No hace falta instalarlo: lo abrís y listo.

{% if agent_available %} Windows {% endif %} {% if agent_mac_arm or agent_mac_intel %} Mac {% endif %} {% if not (agent_available or agent_mac_arm or agent_mac_intel) %} Todavía no está publicado: el administrador tiene que configurar AGENT_DOWNLOAD_URL. {% endif %}

2Pegá tu token en el agente

Va en el campo Token de acceso de la configuración del agente.

3Vinculá tus cuentas

En el agente, botón Cuentas: te logueás como en el navegador y la sesión queda guardada.
